void arch_hypervisor_init ( unsigned const  cpunum,
hyp_flags_t const  hyp_flags 
)

IMPORTANT: it's critical to realize that when the CPU is put into VHE mode, accesses to most EL1 registers become access to EL2 registers. This function is where the switch to EL2&0 happens and if the hypervisor is being enabled for VHE/Host EL2 operation, then any EL1 register configuration performed prior to calling this function will not be transfered to EL2.
