NOTE: Depends on pci_read_cfg32 (architecture specific)

This is architecture independant code expressed in terms of the architecture specific pci_read_cfg32. In other words, to use this function, the target architecture must have implemented pci_read_cfg32. For an example of this, refer to x86/pci_read_cfg32.c.

We don't support unaligned 16bit reads.
