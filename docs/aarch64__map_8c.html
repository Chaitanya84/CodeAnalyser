91/*
92 * Allocate initial page tables required for startup mappings:
93 *
94 * L1_ttbr1 is used to map 39/42 bits of system address space.
95 * This is used to map bootstrap executables and syspage/callouts etc.
96 *
97 * L1_ttbr0 is used to map the low 39/42 bits of address space.
98 * This is used to to create an identity mapping for _vstart.
