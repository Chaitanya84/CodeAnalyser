53// NOTES:
54//
55// An initiator may not mix the use of tagged and untagged queuing for I/O
56// processes to a logical unit, except during a contingent allegiance or
57// extended contingent allegiance condition when only untagged initial
58// connections are allowed.
59//
60// If the disconnect privilege is not granted in the IDENTIFY message for
61// a tagged I/O process, the target will return BUSY status.
62//
63// A series of linked commands constitue a single I/O process. These
64// commands are assigned the queue tag established in the initial
65// connection.
66//
67// The cam_status is | with CAM_SIM_QFRZN.
