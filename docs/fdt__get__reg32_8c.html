Extracts the value of a reg property into the given 32-bit address and size pointers.

Parameters
fdtDevice tree
nodeThe node to look for the reg propery under
indexFor a multiple value property, the index of the value to extract
addrHolds the address portion of the value, upon successful return
sizeHolds the size portion of the value, upon successful return
Returns
0 if addr is non-NULL and the function is successful >=0 if addr is NULL, in which case the returned value is the number of values associated with the property <0 in case of an error
